# 从转写到可以复核的初剪

剪辑者要解决的是反复听素材、记时间和试剪的成本。首次交付应是一份能试听、改顺序、保留或舍弃的初剪，而不是不可解释的自动成片。

## 0.3 决策与边界

- 本地 faster-whisper 负责转写与词时间戳，不判断观点价值、画面质量、噪声或是否跑题。未测项目留空。缺少模型或识别失败要报错，不能用前 12 秒空白内容冒充转写。
- 默认按输入的源素材顺序保留完整识别片段；不再用几个中文关键词猜角色、按虚构分数重排叙事。长片段提示复核，不按秒截断句子。ASR 片段也未必是完整句子，仍需试听。
- 同源相邻片段的延长不跨入邻居正文；重叠原始区间只保留先出现者，报告其他候选。总时长和片数是初选约束，所有排除理由可见。用户可在审核台恢复未入选候选。
- 审核台支持原视频局部播放、选择、移动、改入出点、撤销、导出审核会话与 CSV。浏览器只读用户选择的本地文件，关闭页面释放；不上传、不自动持久化。
- 用户确认后运行 FFmpeg，按审核 CSV 的 order 排序。混合分辨率、帧率及无音轨素材统一为 720p/30fps/48kHz 双声道后拼接。保留原素材、中间片段和报告，拒绝覆盖旧结果。
- 不做字幕翻译/烧录、全自动语义剪辑、音质诊断或审美打分；反馈只调整显式偏好，不声称训练了模型。
- 更紧凑的偏好会下调长片段提示阈值，不自动截断。角色/主题偏好只留作用户记录，当前初选不会据此进行语义排名。

## 可见状态与验证

无文件时可打开标明虚构的示例；导入失败保留当前草稿。试听需要明确选取对应源文件，加载失败保留选择和时间点。导出前检查所有时间范围，至少保留一个片段。撤销恢复选择、顺序及时间。会话可重新导入继续审核，但需重新关联源文件。

## 视觉方向

用户已授权按产品判断完成设计，并指定蓝紫、高级灰、留白。Operate 模式，主操作是审核后导出时间线。候选依据依次为审片台、场记板、广播编排单、摄影接触印样、采访转录纸、字幕校对表、磁带标记纸。Impeccable ed067edc 抽到第六项，采用字幕校对表：左侧连续文本与精确时间，右侧稳定试听窗口，下方紧凑选择带；手机改为顺序阅读。

实验计数器、单色老桌面、参考书中轴、园区地图、折叠纸和云采石场的表达均会转移对文本与切点的注意，拒绝作为世界。吸收它们的固定数字对齐、明确选中态、紧凑注释和可逆变化纪律，不借用装饰。计时以等宽数字表现，界面文字使用系统 UI 字体便于本地离线使用。灰白底、深蓝操作、少量紫色选中态；点阵仅用于待关联媒体的空预览。无装饰性数据、无无限动画、无“·”分隔符。

## 验收目标

实际合成素材跑过转写、初选、浏览器试听修改、CSV 导出、FFmpeg 拼接与 ffprobe；源文件哈希不变。覆盖混合帧率/尺寸、无音轨、乱序 CSV、非法区间、重叠、全部舍弃、撤销和会话恢复。指标以技术结果记录，不推导真实剪辑者效率提升。
