# 工作流

当前版本操作以 [README](../README.md) 为唯一命令入口。

```mermaid
flowchart LR
 A[用户选定的本地视频] --> B[faster-whisper 转写与词时间戳]
 B --> C[CSV 索引与 ASR JSON]
 C --> D[完整片段初选与排除理由]
 D --> E[浏览器试听与可逆调整]
 E --> F[审核 CSV]
 F --> G[明确确认后 FFmpeg 标准化拼接]
 G --> H[视频与源文件哈希报告]
```

JSON 插件可从已有索引直接进入初选；不暗中转写或渲染。批量 ASR 只加载一次模型；逐文件记录 ok/no_speech/error。任何源文件失败均不能报告全量转写成功。

审核会话 JSON 保留片段选择、顺序和切点，可再次导入。源媒体仅通过浏览器 File API 读取，刷新后需重新关联。所有运行结果在 output/，私人源媒体不入 Git。开发示例均虚构。

渲染输出统一为 720p、30fps、48kHz 双声道。按 order 而非 CSV 物理行排列播放，空音轨补静音；不翻译或烧录字幕。失败保留中间文件及失败报告，重新运行使用新目录。
