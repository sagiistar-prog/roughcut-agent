# 技术验收

0.4 的字幕导出、真实 ASR 与 SRT/VTT 联调见 [字幕验收](captions.md)。以下保留 0.3 审核台与转写验收，不能将小样本技术结果外推到用户效果。

## 0.3 基础能力

日期：2026-09-18。证据范围为本地 Windows、真实浏览器和自行生成的测试素材，结果汇总见 acceptance-03.json。GitHub 当前提交检查独立记录在发布清单。

## 已运行

- 20 项 Python 测试通过，其中真实 FFmpeg 集成验证混合分辨率/帧率、静音源补音轨、CSV 行乱序按 order 播放、最终画面先蓝后红、原素材哈希及禁止覆盖。
- faster-whisper 1.2.1 / tiny.en / CPU int8 在两段自行生成的英文 TTS 视频上实际运行，生成 4 个片段，均保留词时间戳及原始转写。两段小样本标准化 WER 均为 0，不外推到自然语音或中文。
- 浏览器读取真实模型生成的 JSON，关联源视频并实际播放，修改切点、下载审核 CSV；FFmpeg 随后生成 21.121 秒视频，原文件哈希不变。
- Chrome 桌面 1440 和手机 390 宽度：导入、保留/恢复、移动、撤销、错误输入保留草稿、会话恢复、全部舍弃、导出均通过。axe 指定 WCAG A/AA 扫描无命中、无页面错误和横向溢出。不是完整无障碍认证。
- 审核台只监听 loopback，仅提供白名单静态资源；伪造 Host 返回 403，原媒体路径请求返回 404。
- Impeccable 检测器 DEGRADED（缺少 HTML 解析模块），regex 无命中，不作为完整检查通过。独立收尾评审见 design-review.md。

## 复现与限制

README、docs/recruiter-demo.md 与 .github/workflows/quality.yml 给出复现命令。ASR 模型首次下载需要网络；FFmpeg 是显式系统依赖，不附带二进制。示例和自动测试不需要真实私人素材。

未开展真实剪辑者试用、自然语音/多说话人/中文语音质量评估或专业剪辑审美评估。审核勾选与 --reviewed 是用户声明，不能证明人真的听过。未测试所有插件宿主的安装。技术成功不等于客户效果。
